# Білім Аралы (kids-platform-kz)

Детская образовательная платформа. Игры и видео по школьной программе, на 4 языках (RU / ҚАЗ / EN / 中文).

## Структура

```
kids-platform-kz/
├── index.html              — главная страница
├── assets/
│   ├── styles.css          — общий стиль всей платформы
│   └── i18n.js             — переводы всех страниц (ключ → 4 языка)
├── grades/
│   └── grade-1/             — 1 класс
│       ├── math/            — предмет: Математика
│       ├── reading/         — предмет: Грамота
│       └── kazakh/          — предмет: Казахский язык
└── games/                    — общий движок для игр, переиспользуется между классами
```

## Как добавить новый класс

1. Скопировать `grades/grade-1/` в `grades/grade-N/`
2. Добавить новые ключи переводов в `assets/i18n.js` для этого класса
3. Подключить `assets/styles.css` и `assets/i18n.js` в новой странице

## Хостинг

GitHub Pages — бесплатно, без сервера. Включается в Settings → Pages.

## Опора на программу

Контент строится по официальным типовым учебным программам РК (Приказ Министра просвещения РК от 16.09.2022 №399, с изменениями на 2025 год).

Ключевая развилка — язык обучения в школе. Программы для 1 класса различаются по предметам:
- **Русская школа**: «Букварь» (I полугодие) + «Обучение грамоте» (II полугодие) + отдельный предмет «Казахский язык» (1-4 кл., как второй язык)
- **Казахская школа**: «Әліппе» + «Ана тілі» (другая методика, не то же самое, что перевод русского контента)
- Также есть уйгурское/узбекское/таджикское направления — планируются отдельным этапом позже

Порядок работы: сначала полностью закрываем **русское направление** по каждому классу (1, 2, 3…), затем **казахское направление** по тем же классам, затем остальные языки обучения.

Предмет «Математика» — общий для всех направлений обучения, не дублируется.
