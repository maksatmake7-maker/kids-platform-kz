# Папка для готовых файлов озвучки (mp3)

Если захотите использовать качественную озвучку (например, через
ElevenLabs.io) вместо встроенного голоса браузера — кладите файлы
сюда по схеме:

    <textKey>-<lang>.mp3

Где:
- `textKey` — ключ текста из `assets/i18n.js` (например `count_explain`)
- `lang` — код языка: ru, kz, en, zh, uz, tg, ug

Пример для объяснения игры "Посчитай и узнай" (ключ `count_explain`)
на всех 7 языках:

    count_explain-ru.mp3
    count_explain-kz.mp3
    count_explain-en.mp3
    count_explain-zh.mp3
    count_explain-uz.mp3
    count_explain-tg.mp3
    count_explain-ug.mp3

Как только файл с правильным именем появляется в этой папке —
сайт начинает использовать именно его при нажатии на "🔊 Озвучить",
автоматически, без изменений в коде. Если файла нет — используется
встроенный синтезатор речи браузера (текущее поведение).

## Как сгенерировать через ElevenLabs

1. Зарегистрируйтесь на elevenlabs.io
2. Возьмите текст нужного объяснения из assets/i18n.js (например
   значение ключа `count_explain` для нужного языка)
3. Сгенерируйте озвучку в интерфейсе ElevenLabs, скачайте mp3
4. Переименуйте файл по схеме выше и загрузите в эту папку на GitHub
